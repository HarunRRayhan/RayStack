# Voice file

Copy to `.raystack/voice.md` (this repo) or `~/.raystack/voice.md` (every repo) and fill it in
from 3-5 of your own posts. Keep each section short. Write "not set" for anything you don't
know yet. The blog skills read these sections by heading, so keep the headings as they are.

## Tone

How you sound, in two or three lines. Who you write for. First person or not.

## Openings

How your posts start. A real incident, a claim, a question? Quote one or two of your own
opening lines.

## Sentences

Length, contractions, numbers, jargon. Quote a line that sounds most like you.

## Never

Words, phrases and habits to cut. One per bullet.

## Formatting

Headings, lists, code blocks, tables, images. Markdown or HTML. Anything your site needs.

## Closing

How a post ends, and the exact links or sign-off line to use.

## Cover footer

domain: not set
handle: not set

## Topics and stack

What you write about and the tools you know first-hand.

## Ideas file

Optional path to a file of topic ideas, e.g. `docs/blog-ideas.md`. Leave "not set" if none.
